## Modules and Required Topics

### CS2AI - Artificial Intelligence

Semester 2, includes a groupwork element. Syllabus provisional (briefing not in repo);
builds on CS1AC and feeds the Year 3 module CS3AM.

| Topic | Details |
| --- | --- |
| Problem Solving | Agents, uninformed and informed search (BFS, DFS, A-star) |
| Knowledge and Reasoning | Knowledge representation, logic, expert systems, reasoning under uncertainty |
| Learning | Machine learning introduction, decision trees, neural networks |
| Applications | Computer vision and NLP ties, evolutionary computation revisit |

### CS2ON - Operating Systems and Computer Networking

Semester 2. **50% technical report (7 pages, due Teaching Week 10)** + **50% written exam (2 hours, assessment period)**.

| Topic | Details |
| --- | --- |
| Operating Systems | Process management, scheduling (FCFS, SJF, SRTF, priority, round robin) |
| Memory Management | Segmentation, paging, virtual memory |
| Storage and I/O | File systems, I/O management, protection domains, authentication |
| Networking | Multi-tier architectures, Ethernet, TCP/IP, IP addressing, routing, congestion control |
| Internet Applications | Email, web, DNS |
| Network Security | Wireless networks, cryptography, firewalls, intrusion detection |

### CS2SD - Software Systems Design

Semester 2. Design report **Stage 1 (group, 40%, due Teaching Week 7)** + **Stage 2 (individual, 60%, due Teaching Week 12)**.

| Topic | Details |
| --- | --- |
| OOAD | Object-oriented analysis and design theory and process |
| UML | Modelling requirements and specifications, design concepts |
| Domain Modelling | Modelling requirement specifications in domain contexts |
| Validation | Validating models through input/output relationships |
| Evaluation | Ethics, extensibility, reusability |
