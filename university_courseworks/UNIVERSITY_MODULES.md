# University Modules (2025/2026 - 2027/2028)

Rolling reference for the owner's undergraduate degree - **BSc Computer
Science** (UCAS code **G400**, three-year full time) at **University of
Reading**, Department of Computer Science. A-level entry **BCC** (or CCD with
a C in Maths/Computer Science); IB 26 points (or 24 with HL4 Maths/Computer
Science). *(Those figures match the page's August 2025 Clearing offers; the
standard offer earlier in the 2025/26 cycle was **ABB** - see the Wayback
captures below.)* The programme is accredited by **BCS, the Chartered
Institute for IT** (subject to reaccreditation in 2029 - per the 2026/27
page) and covers C, C++, Java, Python and
JavaScript across its modules.

This file summarises, per academic year: dates, the modules taken, the
instructions/objectives from the official course pages and departmental
briefings, and each module's catalogue entry.

- Full week-by-week study plans for Year 2: `year2/YEAR2_SEMESTER1.md`,
  `year2/YEAR2_SEMESTER2.md`.
- Local briefing copies: `university_courseworks/year1`, `year2`, `year3`.
- Catalogue links resolve for the owner's institutional login; school code is
  `MPS CS|MPS MATHST|MPS MET` throughout.

## Degree-Wide Rules (from the briefings)

- **Progression (to Year 2):** at least 40% in individual modules totalling
  no less than 80 credits, and at least 30% across the 120 credits. Fails can
  be resat in summer, but a resit mark is capped at 40%.
- **Degree classification:** weighted 1/3 (Year 2 average) + 2/3 (final year
  average); the final-year Degree Project (CS3IP) carries double weight.
- **Discipline:** submit all coursework on time; start project work early.

## Year 2 - 2026/2027

**Dates:** Semester 1 Mon 28 Sep 2026 - Thu 17 Dec 2026 (week off Mon 2 Nov -
Sun 8 Nov); Semester 2 Mon 1 Feb 2027 - Fri 28 May 2027 (assessment period
Mon 10 May - Fri 28 May).

### Modules (2026/27, all compulsory)

| Semester | Module | Title |
| --- | --- | --- |
| 1 | CS2DA | Data Structures and Algorithms |
| 1 | CS2PP | Programming in Python |
| 1 | CS2SE | Software Engineering & Professional Development |
| 2 | CS2AI | Artificial Intelligence |
| 2 | CS2ON | Operating Systems and Computer Networking |
| 2 | CS2SD | Software Systems Design |

### Instructions & objectives

- All modules are compulsory. CS2AI and CS2SD include groupwork elements.
- **CS2PP (verified against the live 2026/7 catalogue):** 20 credits, Level 5,
  Semester 1, convenor Dr Todd Jones. Assessed 40% set exercise (Basics of
  Python, due Teaching Week 7) + 60% group Python application project
  (demonstrated in Assessment Week 2). Learning outcomes: implement
  algorithms in Python scripts/applications; combine imperative, functional
  and OOP paradigms; integrate third-party libraries; apply clean-code best
  practice. Topics include data types, control flow, modules/OOP, I/O, errors
  and exceptions, GUI, web, data science and image manipulation.
- **CS2AI (from the briefing now in the repo, `CS2AI~0022~20267.htm`):**
  20 credits, Level 5, Semester 2, convenor Dr Ferran Espuny Pujol.
  Pre-requisite CS1MA (or MA1LA); co-requisite CS2PP. Assessed **50% written
  exam (2 hours, remote unsupervised)** + **50% group technical report (7
  pages, due Teaching Week 12)**. Aims: adversarial search, game theory,
  supervised/semi-supervised/unsupervised learning, reinforcement learning
  and neural networks/deep learning, applied to classification, regression,
  predictive modelling and information extraction.
- CS2DA: 50% open exam + 50% technical report (7 pages, due Week 11).
- CS2SE: group technical report Stage 1 (50%) + Stage 2 (50%).
- CS2ON: 50% technical report (7 pages, due Teaching Week 10) + 50% written
  exam (2 hours).
- CS2SD: design report Stage 1 (group, 40%, due Week 7) + Stage 2
  (individual, 60%, due Week 12).
- Full week-by-week plans and readiness gaps: `year2/YEAR2_SEMESTER1.md` /
  `year2/YEAR2_SEMESTER2.md`.

## Year 3 - 2027/2028

**Dates:** provisional - final year teaching begins late September 2027 (per
the Year 2 Semester 2 summer plan); confirm the 2027/28 calendar.

### Modules (indicative, from the course page and final-year briefing)

The course page layout: **Degree Project (CS3IP), compulsory, plus four
optional modules** - two chosen from {CS3VR, CS3DV, CS3AM} and two from
{CS3IV, CS3BC, CS3TM, CS3CS}. The local final-year briefing (for the previous
cohort) instead split them: Semester 1 `CS3IP + CS3AM + 1 of {CS3DV, CS3VR}`,
Semester 2 `CS3IP + 2 of {CS3BC, CS3CS, CS3IV, CS3TM}`. Treat the split as
indicative until registration 2027.

| Module | Title | Data-science relevance |
| --- | --- | --- |
| CS3AM | Machine Learning (AI & ML) | MLPs, CNNs, RNNs, attention/transformers, generative AI - the closest fit to the career plan |
| CS3DV | Data Integration and Information Visualisation | raw data to visual insights, commercial tools |
| CS3VR | Virtual Reality, Games and Graphics | graphics-heavy; not data-science aligned |
| CS3BC | Blockchain and Security | blockchain deployment, security |
| CS3CS | Cloud-based AI Solutions | software engineering for scalable AI in the cloud |
| CS3IV | Image Analysis and Visual Intelligence | computer vision |
| CS3TM | Text Mining and Natural Language Processing | lexicons, syntax, semantics |

### Instructions & objectives

- **CS3IP (Degree Project) is 2/9 of the final degree mark** (double-weighted):
  engage with supervision early and start work on the project straight away.
- CS3AM builds on CS2AI; push the maths/ML foundations during Year 2.
- Recommended elective set for the data-science direction (if offered):
  CS3AM, CS3DV, CS3CS and CS3TM.
